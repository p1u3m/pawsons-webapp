โครงเว็บนี้เริ่มจากหน้า Entry เป็นหน้าหลักที่ผู้ใช้เลือกเข้าไปได้ 6 ส่วน:
1. Quiz — ทำแบบทดสอบแล้วไปหน้า Results เพื่อดูผล จากนั้นเลือกไปดู Character ที่เกี่ยวข้อง หรือแชร์ผลออกไปภายนอกผ่าน IG Story Cards ซึ่งต่อยอดเป็น Stickers / GIFs ได้ และมีทางเชื่อมกลับมาหน้า Character
2. Character — หน้ารวมข้อมูลตัวละคร เป็นจุดเชื่อมไปยัง Quiz, Shop และ Contents
3. Houses — หน้าข้อมูลบ้านหรือกลุ่มของตัวละคร แล้วเชื่อมไปดู Character ในบ้านนั้นได้
4. Shop — หน้าร้านค้า เข้าได้ทั้งจากหน้าหลักและหน้า Character
5. Contents — ส่วนเนื้อหา เหมือนเป็น gallery รวบรวมคอนเทนท์หลายหมวด
	เข้าได้จากหน้าหลักและหน้า Character โดยแบ่งเป็น 4 หมวด:
   - 16 Situations — สถานการณ์ 16 แบบ
   - Dukdik — (เว้นไว้ก่อน)
   - Franchise Rosters — (เว้นไว้ก่อน)
   - Pair Conflicts — (เว้นไว้ก่อน)
6. Personal Letters — ส่วนจดหมายส่วนตัวที่ส่งถึงผู้ใช้โดยตรงเหมือนแชทกับตัวละครแต่ต้องรอเหมือนรอจดหมาย แทนรูปแบบ Newsletter (อันนี้ก็เว้นไว้ก่อน)
ในภาพ Character เป็นจุดเชื่อมหลักของการสำรวจเว็บ ส่วน Quiz ช่วยพาผู้ใช้ไปพบตัวละครและแชร์ผลต่อออกไปครับ
